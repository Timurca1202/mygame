# Tiny5

Автор: Stefan Schmidt и The Tiny5 Project Authors.
Источник: https://github.com/google/fonts/tree/main/ofl/tiny5
Оригинальное имя скачанного файла: Tiny5[BLED,JITT,ROND,wdth,wght].ttf.
В проекте: Tiny5-Variable.ttf; файл не модифицирован.
Лицензия: SIL Open Font License 1.1, полный текст в OFL.txt.
Дата добавления в Hypster: 7 ноября 2026.

Используется одной семьёй во всём интерфейсе стрима, включая кириллицу, цифры, меню длительности и всплывающий текст тапа. Размеры основных надписей кратны 10; отключены сглаживание и субпиксельное позиционирование для чёткого пиксельного рисунка.
