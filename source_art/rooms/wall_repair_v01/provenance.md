# Светлые обои — первый ремонт стен

Автор прислал `/Users/timur/Downloads/Unknown-2.webp`, лист четырёх вариантов комнаты. Неизменённая копия сохранена в `ref/location/renovation_variants_v01.webp`. Использован только вариант 1, сверху слева: кремовые обои с вертикальным растительным узором. Другие варианты остаются референсами будущих улучшений.

Ассет `assets/art/rooms/e1/repaired_walls_v01.png` получен встроенным `image_gen` через навык imagegen, режим редактирования, непрозрачный фон. Вход 1 — исходная игровая оболочка `assets/art/rooms/e1/room_shell_v01.png` (цель редактирования), вход 2 — лист автора (визуальный референс). Полный промпт: `prompt.txt` рядом с этим файлом. Сгенерированный результат скопирован в проект без изменения исходных изображений.

В игре используется не полная подмена комнаты: `room_silhouette.gdshader` подмешивает новый рисунок только в области стен, сохраняя исходные пиксели пола, наружных краёв, плинтусов, окна, балки и лампы. Мебель, герой и телефон остаются отдельными прежними слоями. Материал копируется для каждого экземпляра комнаты, чтобы ремонты разных профилей не влияли друг на друга.

Стоимость $25 и Vibe +2 — начальные настройки для плейтеста. Это не цена из авторского листа. Ремонт разовый, обратной продажи нет.
