# Hypster

Мобильный 2D-симулятор стримера на Godot 4 и GDScript. Первый целевой формат — iOS, портрет 540×960; Android — следующим этапом.

Главная сцена показывает просторный вариант стартовой комнаты E1 по выбранному автором референсу `ref/location/Unknown.webp` (левый вариант). По просьбе автора увеличена площадь комнаты: перед столом и по бокам больше свободного пола. Комната собрана из фона, стола с предметами и табурета как отдельных узлов; мебель использует PNG с прозрачностью. Слои подготовлены встроенным imagegen по утверждённому арту `assets/art/rooms/e1/poor_corner_expanded_v01.png`; исходные изображения сохранены. Рендер сборки в 540×960 визуально проверен: `source_art/rooms/start_room/layered_room_preview_v01.png`. Герой, анимации, интерфейс и игровые механики ещё не реализованы.

## Открытие

В менеджере проектов Godot 4 выбрать **Импортировать** и указать `project.godot` из этой папки. Главная сцена — `scenes/app/main.tscn`.

Проверенный движок: **Godot 4.7.2.stable.official.ed1daf0bf**, найден в `/Users/timur/Downloads/Godot.app`. Импорт выполнен, короткий запуск статичной сцены через headless CLI завершился без ошибок после разрешения стандартной записи журнала Godot. Визуальная проверка окна игры ещё не выполнена.

## Каталоги

| Путь | Назначение |
|---|---|
| `Hypster_GDD.md` | Основной дизайн-документ, сохранён на исходном месте |
| `ref/` | Оригиналы визуальных референсов, только для чтения |
| `scenes/` | Сцены приложения, комнаты, персонажей, стрима и UI |
| `src/` | GDScript: логика, контроллеры, сервисы, типы ресурсов |
| `assets/` | Подготовленные для игры изображения, звук и шрифты |
| `source_art/` | Редактируемые исходники графики и звука |
| `data/` | Каталоги предметов, баланс, события, диалоги, локализация |
| `docs/` | Архитектура, арт-направление, решения, планирование |
| `tests/` | Будущие тесты логики, интеграций и тестовые данные |
| `tools/` | Будущие инструменты импорта, баланса и валидации |
| `addons/` | Godot-плагины, когда они потребуются |
| `builds/` | Локальные экспортированные сборки, исключённые из Git |

В пустых каталогах `.gitkeep` сохраняет структуру для будущего Git-репозитория. `.gdignore` исключает документацию, референсы, исходники и инструменты из сканирования ресурсов Godot. Git-репозиторий пока не инициализирован.

## Соглашения

- Имена файлов и каталогов — `snake_case`; узлы сцен и классы — `PascalCase`.
- Например, `scenes/room/room_view.tscn` и `src/room/room_view.gd`.
- Готовые изображения помещаются в `assets/`, а не берутся напрямую из `ref/`.
- Пиксельные текстуры используют nearest-фильтрацию. Масштабирование, safe area и реальное устройство проверяются при создании первого игрового экрана.
- Сервисы, форматы данных и плагины добавляются при реализации соответствующих задач.

Правила для агента — `AGENTS.md`. Карта архитектуры — `docs/architecture/project_structure.md`.
