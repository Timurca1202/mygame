# Реакции героя и живой экран — v05

В существующую игровую сцену добавлены локальные анимации исходного героя. Комната, мебель, посадка, исходные PNG и неоновый интерфейс сохранены. Это небольшой набор для текущего прототипа, не полная система персонажа из GDD.

| Событие | Движение |
|---|---|
| Ожидание | Прежнее спокойное дыхание с циклом 4.8 секунды |
| Тап | Короткий наклон головы и подъём плеча, 0.36 секунды |
| Верный ответ / участие в опросе | Выразительный кивок и расправление плеч, 0.85 секунды |
| Ошибка / пропуск вопроса | Два движения головой в стороны, 1 секунда |
| Благодарность донатеру | Двойной поклон головы, 1.45 секунды |
| Высокий нагрев | Постепенно опущенная голова и плечи; с 70% появляются две маленькие капли пота |

Шейдер поворачивает голову вокруг шеи и отдельно деформирует плечевую область. Кисти, таз, ноги и обувь сохраняют исходные координаты. Движется не весь спрайт. Тапы не перебивают ответы и благодарность; благодарность имеет высший приоритет. Повторные тапы не перезапускают ещё не законченную реакцию, очередь не накапливается.

У существующего телефона появился небольшой анимированный индикатор активности и слабый свет: с ростом хайпа индикатор становится активнее, нагрев плавно меняет оттенок с голубого на тёплый. В готовности и на итогах индикатор выключается. Новые предметы в комнату не добавлялись.

`src/room/stream_atmosphere.gd` наблюдает за счётчиками сессии. Он не изменяет время, хайп, ответы, доход или сохранения. `src/characters/seated_reactions.gd` задаёт локальную позу. При паузе, включая потерю фокуса приложения, замирают реакция, дыхание, пыль, капли и индикатор телефона. Новый эфир сбрасывает наблюдаемые счётчики.

## Проверка

Godot **4.7.2.stable.official.ed1daf0bf**. Все 170 проверок существующей логики проходят; UI integration — 0 ошибок. Сценарии сохранения используют собственные тестовые профили; `user://profile.json` не изменялся.

Дополнительный сценарий проверяет реальные пиксели 18 фаз каждой реакции: изменения есть, изменений в областях кистей, таза и ног — 0. Проверяются приоритет благодарности, заморозка шейдера и совпадение рендера во время паузы, а также запуск реакций через действия существующего UI. Экспортируется 180 кадров, 12 кадров/с, 15 секунд. Общий игровой экран и крупные планы просмотрены. На физическом iPhone не проверено.

Запускать рендеры последовательно: другое окно Godot может вызвать предусмотренную игрой паузу при потере фокуса.

Материалы в `source_art/prototypes/stream/`:

- `stream_reactions_v05.gif` — действующий игровой экран: ожидание → тапы → верный ответ → ошибка → благодарность → нагрев → пауза → продолжение. Переходы между событиями ускорены сценарием проверки; сами анимации идут в реальном времени.
- `hero_reactions_v05.gif` — тот же отрезок, крупный план ×4 с nearest-фильтрацией.
- `reactions_*_v05.png` — отдельные фазы и детали.
- `stream_*_v05.png` — состояния UI из существующего интеграционного сценария. Рендеры v04 сохранены.

Решение остаётся локальной деформацией утверждённого изображения. Новые ракурсы, смена одежды, речь с артикуляцией рта и движения кистей потребуют отдельных художественных кадров.
