# Экономия контекста и RTK

По указанию автора установлены `context-optimization` (`/Users/timur/.codex/skills/context-optimization/SKILL.md`) и RTK OSS 1.2.0 (`/Users/timur/.local/bin/rtk`). Навык получен из `muratcankoylan/Agent-Skills-for-Context-Engineering` на ревизии `9ff0c99108b36d3b886defd825d8ac1f47dba374`; бинарник RTK — из официального релиза `rtk-ai/rtk` v1.2.0 для macOS arm64, SHA-256 проверен по файлу контрольных сумм релиза. Системный Node.js для этих инструментов не требуется.

Рабочий подход: адресный поиск и чтение, отсутствие ненужных повторов, полные большие логи во временных файлах, краткие результаты в контексте. В обзорах использовать RTK там, где он помогает; при анализе конкретной ошибки или правки читать полные исходники и нужные участки diff. Установка не меняет настройки провайдеров, системные инструкции, механизм сжатия Codex или автоматические хуки.

## Замер 8 ноября 2026

Один локальный прогон на текущем рабочем дереве Hypster. В обоих случаях выполнялись одинаковые команды; измерены байты stdout и stderr без цветовых ANSI-кодов. Это не измерение токенизатором модели и не оценка общей стоимости чата.

| Команда | Обычный вывод, байт | RTK, байт | Сокращение |
|---|---:|---:|---:|
| `git status` | 2119 | 1666 | 21.4% |
| `git diff --stat` | 1268 | 1268 | 0% |
| `git diff` | 68860 | 37696 | 45.3% |
| Godot: `test_heat_and_moderation.gd` | 121 | 121 | 0% |
| Godot: контрольная ошибка с кодом завершения 0 | 281 | 208 | 26.0% |

Все сравниваемые команды завершились с кодом 0. Обычный тест Godot прошёл 28 проверок без ошибок в обоих запусках. Контрольный скрипт находился в `/tmp`, специально выводил `RTK_DIAGNOSTIC_PROBE` через `push_error()` и завершался кодом 0. Маркер сохранился после `rtk err`, что подтверждает необходимость отдельно проверять диагностику Godot, а не полагаться только на код завершения. Это один контрольный случай, не доказательство сохранения всех возможных диагностик.

Полные исходные и отфильтрованные результаты, скрипт контрольного случая и JSON измерений сохранены в `/tmp/hypster-rtk-benchmark/`. Размеры вывода Git зависят от состояния рабочего дерева. Для ежедневной работы `git diff --stat` и адресный diff обычно полезнее выгрузки полного дерева изменений. Специальная экономия на логах Godot этим прогоном не подтверждена; прямой запуск Godot остаётся основным способом проверки.
