# Референсы предметов

Прямое указание автора: практически для всех предметов референс уже лежит в `ref/`. Прежде чем готовить ассет, искать соответствующий предмет здесь и следовать его дизайну. Оригиналы не переименовывать, не редактировать и не использовать напрямую как игровые текстуры: готовые прозрачные ассеты — в `assets/`, промпты и происхождение — в `source_art/`.

## Техника

- `ref/device/Main/` — устройства для стрима.
- `ref/device/camera/` — камеры.
- `ref/device/microphone/` — микрофоны.
- `ref/device/light/` — свет: в просмотренном листе L1 настольная лампа, L2 LED-лента, L3 кольцевая лампа, далее студийные приборы.
- `ref/device/wind/` — охлаждение: верхний ряд №1 подставка, №2 маленький вентилятор, №3 вытяжка, №4 мобильный кондиционер; нижний ряд — следующие ступени.
- `ref/device/table/` — столы.
- `ref/device/ chear/` — сиденья (пробел в исходном имени сохранён).
- `ref/device/monitor display/` — мониторы.
- `ref/device/accesuars/` — аксессуары.

Категории перечислены по исходным каталогам. Перед добавлением конкретной техники открыть сам лист, а не судить о её дизайне только по имени папки. Утверждённые комната и UI остаются привязаны к своим референсам в `ref/location/` и `ref/ui/`.
